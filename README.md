# ✈️ Flight Ticket Price Prediction

## 📌 Project Overview

Flight Ticket Price Prediction is a Machine Learning project that aims to predict flight ticket prices based on various flight-related features.

The project uses Python and Machine Learning algorithms to analyze flight data, identify important patterns, and estimate ticket prices.

## 🎯 Project Objectives

- Analyze flight ticket pricing data.
- Perform data cleaning and preprocessing.
- Identify missing values, duplicates, and outliers.
- Perform Exploratory Data Analysis (EDA).
- Understand relationships between flight features and ticket prices.
- Build and evaluate Machine Learning regression models.

## 🛠️ Technologies & Libraries Used

- **Python** – Programming Language
- **Pandas** – Data Manipulation
- **NumPy** – Numerical Computing
- **Matplotlib** – Data Visualization
- **Seaborn** – Statistical Visualization
- **Sweetviz** – Automated EDA
- **Scikit-learn** – Machine Learning

## 🤖 Machine Learning Algorithms

1. Linear Regression
2. Ridge Regression

## 📊 Dataset Information

The project dataset contains 4,955 records and 12 columns.

Important features include:

- Airline
- Source
- Destination
- Total Stops
- Additional Information
- Date
- Month
- Year
- Arrival Time
- Departure Time
- Duration
- Price (Target Variable)

## 📈 Model Evaluation Metrics

The models are evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
